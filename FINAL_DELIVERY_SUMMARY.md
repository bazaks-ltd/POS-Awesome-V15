## 🚀 How to Get Started

### **Immediate Actions (Next 30 Minutes)**

#### 1. Deploy Backend (5 minutes)

```bash
cd /Volumes/TZARMORSP/wrk/posbaz/frappe-bench
bench --site your.site migrate
bench restart
```

**✅ Checkpoint**: Migrations complete, no errors

#### 2. Build Frontend (3 minutes)

```bash
cd apps/posawesome/frontend
yarn build
```

**✅ Checkpoint**: Build successful

#### 3. Clear Cache (1 minute)

```bash
bench --site your.site clear-cache
```

**✅ Checkpoint**: Cache cleared

#### 4. Configure POS Profile (5 minutes)

- Open POS Profile in ERPNext
- Set "POS Type" = "Grocery Store"
- Set "Device Target" = "Auto"
- Enable "Split Payments"
- Save

**✅ Checkpoint**: POS Profile saved

#### 5. Enable Modular System (1 minute)

Open browser console (F12):
```javascript
window.posFeatureFlags.enableModular();
location.reload();
```

**✅ Checkpoint**: Page reloads with modular system

#### 6. Start Testing (15 minutes)

Follow **[MANUAL_TESTING_CHECKLIST.md](./MANUAL_TESTING_CHECKLIST.md)**

Start with:
- Section: Pre-Testing Setup (tests 1-4)
- Section: Desktop Testing (tests 7-12)
- Section: Critical Path Test (test 39)

**✅ Checkpoint**: Basic functionality works
